# GitHub Description

## Short Repo Description

Local-first rental deposit evidence desk that matches deductions to proof, flags gaps, and drafts a dispute packet outline.

## Longer Description

Deposit Defender Desk helps renters organize security deposit dispute evidence locally. It imports move-in/move-out evidence, landlord deductions, and quick notes, then matches each charge to proof, estimates configured return deadlines, flags evidence gaps, and exports a Markdown/JSON dispute packet outline.

## Alternative Descriptions

1. Turn rental deposit deductions and move-out evidence into a local dispute packet.
2. Match landlord charges to photos, receipts, walkthrough records, and evidence gaps.
3. A privacy-first evidence desk for renters responding to security deposit deductions.
